# پیام آماده برای ارسال به کارفرما / امیررضا

وضعیت پروژه (جدول کامل): [client-project-status.md](./client-project-status.md)

کپی و بفرست. جای ⟨URL⟩ را با لینک عمومی پایدار Netlify پر کنید؛ اگر فقط دموی زندهٔ موقت دارید، همان را بگذارید و بگویید لینک پایدار به‌زودی جایگزین می‌شود.

---

سلام،  
وضعیت فعلی پروژهٔ وب‌سایت **Green Diamond Farm** (بازرگانی حسینی نوه) به این شرح است:

**آماده برای بازبینی شما:** دموی چندزبانه با صفحات اصلی، کاتالوگ ارقام، تماس (ایمیل/واتساپ)، و نسخهٔ عربی راست‌چین.

**لینک مشاهده:** ⟨URL⟩  

لطفاً این مسیرها را ببینید و نظرتان را بفرستید:
1. صفحه اول — برند و حس صادراتی  
2. `/products` — احمدآقایی، اکبری، فندقی، کله‌قوچی، دهن‌بست، مغز و شور  
3. منوی زبان → العربية  
4. `/contact` — واتساپ و ایمیل  

**توجه:** لوگوی فعلی پیشنهادی/موقت است تا فایل لوگوی شما برسد. عکس‌ها نیز تا دریافت تصاویر اختصاصی، نمونه هستند.

اگر همین مسیر بصری را تأیید کنید، مرحلهٔ بعد می‌شود: لوگو و عکس نهایی، تأیید ایمیل/شماره/آدرس، سپس دامنهٔ `greendiamondfarm.com`.

کد پروژه: https://github.com/Arafie3480/Pistachio-Company

## برای خودت قبل از ارسال

1. لینک را باز کن و همان ۴ مسیر را چک کن (یا لوکال: `npm run smoke:ci` روی `:4321`)
2. در صورت نیاز اسکرین‌شات‌ها را ضمیمه کن: `media/demo-*.png`
3. URL پایدار: Netlify Access/password را خاموش کن → `*.netlify.app` — [netlify-public-demo.md](./netlify-public-demo.md)
4. **ممنوع:** Claim/SMS · Workers/`tmp.now` خراب · Netlify با 401 · تونل موقت به‌عنوان دامنهٔ نهایی
5. در صورت تمایل وضعیت کامل را هم بفرست: [client-project-status.md](./client-project-status.md)
