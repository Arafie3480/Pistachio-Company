# پیام آماده برای ارسال به کارفرما / امیررضا

کپی و بفرست. اگر URL عمومی پایدار (Netlify بدون password) آماده است، آن را جای «لینک عمومی» بگذار.
اگر هنوز فقط تونل موقت / لوکال دارید، لینک زندهٔ همان جلسه را بگذارید و بگویید دامنهٔ پایدار بعد از باز شدن Netlify می‌آید.

---

سلام، دموی اولیه وب‌سایت **Green Diamond Farm** آماده است.

**لینک عمومی:** ⟨URL⟩  
مسیرهای پیشنهادی:
1. صفحه اول — برند و حس صادراتی  
2. `/products` — ارقام احمدآقایی، اکبری، فندقی، کله‌قوچی، دهن‌بست، مغز و شور  
3. از منوی زبان → العربية (راست‌چین)  
4. `/contact` — واتساپ و ایمیل  

چندزبانه آماده است (EN/AR/TR/ZH/HI/RU).  
لوگوی فعلی پیش‌فرض است تا فایل لوگوی شما برسد.

اگر همین مسیر را تأیید کنید، برای دامنه نهایی (دامنه/DNS، عکس محصول، لوگو نهایی) جلو می‌رویم.

کد: https://github.com/Arafie3480/Pistachio-Company

## برای خودت قبل از ارسال

1. لینک عمومی را باز کن و همان ۴ مسیر بالا را چک کن (یا لوکال: `npm run smoke:ci` بعد از build روی `:4321`)
2. اسکرین‌شات: `media/demo-home-en.png` · `demo-products-en.png` · `demo-home-ar.png` · `demo-contact-en.png`
3. URL پایدار (بدون Vercel): Netlify → Access control / Visitor access → **خاموش کردن password** روی سایت متصل به این ریپو → Publish `main` → `https://<site>.netlify.app`
4. **ممنوع:** Claim/SMS ایران · لینک Workers/`tmp.now` خراب · Netlify با Access/401 · تکیه به تونل موقت به‌عنوان دامنهٔ نهایی
5. پیام بالا را برای کارفرما بفرست و تأیید بگیر
