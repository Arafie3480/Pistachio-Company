سلام،  
دموی اولیه وب‌سایت **Green Diamond Farm** (بازرگانی حسینی نوه) آماده بازبینی است.

**لینک مشاهده:** ⟨URL⟩  

لطفاً این مسیرها را ببینید:
1. صفحه اول — لوگوی رسمی و حس صادراتی  
2. `/products` — احمدآقایی، اکبری، فندقی، کله‌قوچی، دهن‌بست، مغز و شور  
3. منوی زبان → فارسی یا العربية (راست‌چین)  
4. `/contact` — واتساپ و ایمیل  

چندزبانه: EN / FA / AR / TR / ZH / HI / RU  
لوگوی رسمی نشسته؛ عکس‌های فضاساز تا دریافت تصاویر اختصاصی شما نمونه هستند.

اگر مسیر را تأیید کنید، طبق پیش‌فاکتور با پرداخت **۵ میلیون از ۱۰ میلیون تومان (۵۰٪)** ادامه می‌دهیم (اصلاحات، لوگو/عکس شما، آماده‌سازی دامنه).

1. لینک را باز کن و ۴ مسیر بالا را چک کن
