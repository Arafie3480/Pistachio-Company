# راهنمای کوتاه کارفرما — فقط محتوا

سایت روی قالب اختصاصی **Green Diamond Farm** است. ظاهر قفل است تا به‌هم نریزد.

## کجا ویرایش کنم؟

پیشخوان وردپرس → **ظاهر (Appearance)** → **Site Content**

1. تب زبان را انتخاب کنید (مثلاً فارسی).  
2. متن یا توضیح محصول را عوض کنید.  
3. اگر فیلدی را خالی بگذارید، متن پیش‌فرض قالب همان زبان می‌ماند.  
4. **ذخیره** را بزنید.

## تماس و عکس

همان صفحهٔ Site Content:

- ایمیل، تلفن، واتساپ، آدرس  
- لینک تصاویر (وقتی عکس خودتان را آپلود کردید، آدرس فایل را اینجا بگذارید)

## چه کارهایی نکنید؟

- Elementor یا صفحه‌ساز دیگر نصب/فعال نکنید.  
- فایل‌های CSS قالب را دستی عوض نکنید.  
- صفحهٔ خام وردپرس را برای «بازطراحی» ویرایش نکنید؛ متن از Site Content می‌آید.

## سوال یا اصلاح ظاهر

فقط به مجری بگویید — ظاهر از سمت قالب درست می‌شود، نه از پنل محتوا.
