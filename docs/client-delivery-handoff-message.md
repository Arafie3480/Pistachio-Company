پیشخوان → ظاهر → Site Content → تب همان زبان → ذخیره

1) یک‌بار سایت را کامل ببینید
2) رمز ورود پیشخوان را حتماً عوض کنید

## ب) گزارش کامل تحویل (برای ارسال یا PDF)

### ۱. موضوع
تحویل فنی وب‌سایت بازاریابی/صادراتی **Green Diamond Farm** (بازرگانی حسینی نوه) روی دامنه رسمی.

### ۲. وضعیت فعلی
| مورد | نتیجه |
|------|--------|
| دامنه | https://greendiamondfarm.com — فعال |
| نسخه قالب | **1.0.7** |
| ظاهر | قفل‌شده مطابق دموی تأییدشده |
| ویرایش محتوا | فقط Appearance → Site Content |
| Elementor / صفحه‌ساز آزاد | استفاده نشده (عمداً) |

### ۳. اقلام تحویل‌شده (داخل اسکوپ)
1. طراحی و پیاده‌سازی ۵ صفحه: خانه، درباره، محصولات، تماس، حریم خصوصی  
2. چندزبانه: EN · FA · AR · TR · ZH · HI · RU (FA/AR راست‌چین)  
3. هویت بصری: لوگو رسمی، پالت سبز/طلایی  
4. تماس: ایمیل، تلفن، واتساپ، آدرس انبار  
5. SEO پایه: description، canonical، Open Graph، hreflang  
6. پنل فقط‌محتوا برای متن، محصولات، تماس و URL عکس‌ها  
7. پایدارسازی پس از go-live: حذف اثر Blocksy/Stackable، سوییچر زبان، جلوگیری از گیج شدن با Google Translate، اصلاح نمایش آدرس فارسی  
8. کاتالوگ محصول باز: کارت با جای عکس + صفحه جزئیات هر رقم (توضیح، سایز/درجه، نمونه عکس)

### ۴. لینک‌های بازبینی
| صفحه | لینک |
|------|------|
| خانه | https://greendiamondfarm.com/ |
| فارسی | https://greendiamondfarm.com/fa/ |

| تماس | https://greendiamondfarm.com/contact/ |

### ۵. آموزش کوتاه محتوا
- هر زبان **جدا** است؛ ترجمه خودکار وجود ندارد.  
- فیلد خالی = برگشت به متن پیش‌فرض همان زبان.  
- عکس محصول: Site Content → Images / Product photo → ذخیره.

### ۶. اقدامات کارفرما (باز)
1. تعویض رمز wp-admin  
2. بازبینی نهایی متن  
3. ارسال عکس اختصاصی (اختیاری ولی توصیه‌شده)  
4. پرداخت مرحله ۲ طبق پیش‌فاکتور خصوصی  
5. فعال نکردن دوباره Blocksy / Companion / Stackable  

### ۷. خارج از این تحویل
پشتیبانی ماهانه بلندمدت، بازطراحی گسترده، صفحه‌ساز آزاد، تبلیغات و تولید محتوای مداوم — نیاز به توافق جدا (پیشنهاد زیر).
