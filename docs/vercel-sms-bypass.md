# مسیر عمومی دمو (بدون جزئیات حساب)

این فایل قبلاً یادداشت داخلی استقرار بود. جزئیات حساب، مسیر لوکال ماشین، و دستورهای claim/SMS از ریپوی public حذف شده‌اند.

## مسیر پیشنهادی برای لینک پایدار

1. **Netlify** — Import از GitHub → Framework Next.js → Deploy → خاموش‌کردن password (Access control).  
2. **Cloudflare Pages** — Connect Git → preset Next.js → `*.pages.dev`.  
3. تونل موقت (Cloudflare quick tunnel) فقط برای جلسهٔ نمایش.

جزئیات عملیاتی حساس فقط در کانال خصوصی تیم نگهداری شود.
