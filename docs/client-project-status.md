## خلاصه یک‌خطی

دموی چندزبانه با لوگوی رسمی، پالت سبز/طلایی، فارسی RTL، و نمایش اعتبار About (**۵۰+ / ۴۰+ / ۳۰+**) آماده بازبینی است. پیش‌پرداخت ۵۰٪ دریافت شده. دامنه هنوز WordPress است؛ لینک پایدار Netlify همچنان نیازمند خاموش‌کردن password است.

## نحوهٔ مشاهده

| روش | اقدام | ماندگاری |
|------|--------|----------|
| لوکال (تیم) | `npm run build && npm run start` → `http://127.0.0.1:4321/en` | پایدار برای تیم |
