## خلاصه یک‌خطی

دموی چندزبانهٔ سایت صادراتی آمادهٔ **بازبینی کارفرما** است. محتوا و مسیرهای اصلی تأیید فنی شده‌اند؛ برای لینک عمومی پایدار باید Access/password سایت Netlify خاموش شود. دامنهٔ فعلی `greendiamondfarm.com` هنوز WordPress است.

## نحوهٔ مشاهده

| روش | لینک / اقدام | ماندگاری |
|------|----------------|----------|
| لوکال (تیم) | `http://127.0.0.1:4321/en` بعد از `npm run start` | پایدار برای تیم |
| عمومی پایدار | بعد از خاموش‌کردن password در Netlify → `*.netlify.app` | هدف برای کارفرما |
| دامنه نهایی | `greendiamondfarm.com` پس از تأیید + DNS | هنوز WordPress |

راهنما: [netlify-public-demo.md](./netlify-public-demo.md)

## در انتظار کارفرما / تصمیم

| مورد | چرا مهم است |
|------|-------------|
| تأیید مسیر بصری دمو | قفل کردن طراحی قبل از دامنه |
| فایل لوگوی رسمی | جایگزینی mark پیشنهادی |
| عکس محصول / باغ / انبار اختصاصی | حذف تصاویر stock |
| گواهی‌ها (در صورت نیاز روی سایت) | اعتماد خریدار |
| تأیید املای ایمیل `export@greendiamondfarm.com` | جلوگیری از bounce |
| شماره واتساپ/تلفن اختصاصی کسب‌وکار | در صورت تفاوت با خط فعلی |
| آدرس کامل‌تر از «انبار، مطهری ۵۲» | دقت تماس |
| تأیید سال‌های تجربه (`historyYears`) | متن About |
| باز کردن Netlify بدون password (تیم میزبان) | لینک عمومی پایدار برای کارفرما |
