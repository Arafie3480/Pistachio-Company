# پیام آماده — نصب قالب روی دامنه

---

سلام،  
قالب نهایی هم‌ظاهر با دموی تأییدشده آماده است. الان روی دامنه قالب Blocksy فعال است؛ با نصب قالب اختصاصی، ظاهر قفل می‌ماند و شما فقط محتوا را از پیشخوان عوض می‌کنید.

برای نصب لطفاً یکی از این دو:

**۱) دسترسی موقت File Manager / ادمین** را خصوصی بفرستید تا خودم نصب کنم.  

**یا ۲)** این دو فایل را در ریشه وردپرس (کنار `wp-config.php`) آپلود کنید، بعد در حالی که لاگین هستید این آدرس را باز کنید:

`https://greendiamondfarm.com/gdf-install.php`

دانلود:
- https://raw.githubusercontent.com/Arafie3480/Pistachio-Company/cursor/wordpress-theme-delivery-3e66/wordpress/gdf-install.php
- https://github.com/Arafie3480/Pistachio-Company/raw/cursor/wordpress-theme-delivery-3e66/wordpress/dist/green-diamond-farm.zip

بعد از نصب موفق، همان دو فایل را از هاست حذف کنید و یک‌بار **تنظیمات → پیوندهای یکتا → ذخیره** را بزنید.
