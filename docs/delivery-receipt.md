## آموزش کوتاه کارفرما (فقط محتوا)

1. ورود به https://greendiamondfarm.com/wp-admin  
2. **ظاهر → Site Content**  
3. تب زبان را انتخاب کنید  
4. متن / محصول / تماس / لینک عکس را عوض کنید → ذخیره  
5. Elementor یا تغییر CSS نصب/فعال نکنید  

جزئیات: [wordpress-client-edit-guide.md](./wordpress-client-edit-guide.md)
