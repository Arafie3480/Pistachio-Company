# پیام برای کارفرما — آپدیت محصولات + آدرس + محتوا

سلام امیررضا جان،

طبق بازخوردتون این‌ها روی سایت زنده اعمال شد:

1. **هیرو بازتر** — عکس پسته روی دسکتاپ هم بهتر دیده می‌شود  
2. **لیست ارقام** — هر رقم کارت جدا با جای عکس دارد  
3. **مغز و شور/بوداده** — بخش جدا از ارقام پوست‌دار  
4. **صفحه جدا برای هر محصول** — با توضیح، سایز/درجه و جای عکس نمونه  
   مثال: https://greendiamondfarm.com/products/akbari/  
   فارسی: https://greendiamondfarm.com/fa/products/akbari/  
5. **آدرس فارسی** — فقط در زبان فارسی نشان داده می‌شود؛ در انگلیسی و بقیه فقط آدرس انگلیسی می‌آید

---

**سوالتون درباره محتوا:**

ترجمه خودکار نداریم. هر زبان **جدا** است.

- متن‌های پایه هر ۷ زبان از قبل داخل قالب است  
- برای ویرایش: پیشخوان → ظاهر → **Site Content** → تب همان زبان → ذخیره  
- اگر فقط فارسی را عوض کنید، انگلیسی/عربی خودکار عوض نمی‌شوند  
- عکس هر محصول را هم از همان صفحه (Images / Product photo) می‌توانید URL بگذارید

اگر عکس‌های واقعی پسته را بفرستید، جای placeholderها می‌گذاریم.
