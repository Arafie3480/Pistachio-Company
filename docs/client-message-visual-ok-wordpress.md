# پیام آماده — تأیید ظاهر + مسیر وردپرس

جای ⟨URL⟩ را با لینک دمو پر کنید.

---

سلام آقای خراسانی،  
از تأیید ظاهر تا این مرحله ممنونم. اگر اصلاح جزئی دیگری بود بفرمایید اعمال می‌کنم.

**وضعیت:** دموی چندزبانه (با لوگو، فارسی، تاریخچه شرکت و تماس) آماده است.  
**لینک:** ⟨URL⟩

برای ادامه دو موضوع را شفاف می‌کنم:

### ۱) داخل توافق فعلی
- اصلاحات جزئی ظاهر/متن که بفرستید  
- جایگزینی عکس و اطلاعات شما  
- آماده‌سازی go-live روی دامنه پس از **پرداخت مرحله ۲**

### ۲) درخواست شما درباره وردپرس
پیاده‌سازی روی وردپرس به‌شکلی که **فقط محتوا** (متن، محصولات، تماس، عکس) از پیشخوان عوض شود و **استایل ثابت بماند**، با نسخهٔ فعلی Next فرق دارد و به‌عنوان **فاز تحویل روی وردپرس** انجام می‌شود:

- قالب اختصاصی هم‌ظاهر با همین دمو  
- ویرایش محتوا از پنل ادمین، بدون به‌هم‌ریختن طراحی  
- بعد از تأیید روی استیجینگ → انتقال به `greendiamondfarm.com`

برای شروع این فاز لازم است:
1. تأیید همین مسیر وردپرس  
2. پرداخت مرحله ۲ (طبق پیش‌فاکتور) قبل از cutover دامنه  
3. دسترسی ادمین وردپرس (فقط خصوصی)

اگر موافقید، همین مسیر را قفل می‌کنیم و زمان‌بندی استیجینگ را اعلام می‌کنم.
