# پیام آماده — تأیید ظاهر + ادامه تحویل وردپرس

جای ⟨URL⟩ را با لینک دمو پر کنید.

---

سلام آقای خراسانی،  
از تأیید ظاهر تا این مرحله ممنونم. اگر اصلاح جزئی دیگری بود بفرمایید اعمال می‌کنم.

**وضعیت:** ظاهر دمو تأیید شده و همان مبنا برای پیاده‌سازی نهایی است.  
**لینک دمو:** ⟨URL⟩

طبق قرار، مرحلهٔ بعد **پیاده‌سازی روی وردپرس** است؛ طوری که:

- ظاهر و استایل مثل همین دمو ثابت بماند  
- شما بعداً بتوانید **فقط محتوا** را از پیشخوان عوض کنید (متن، محصولات، تماس، عکس)  
- طراحی از داخل پنل به‌هم نریزد  

قالب وردپرس هم‌ظاهر با همین دمو آماده است؛ ظاهر ثابت می‌ماند و محتوا از پیشخوان («Site Content») عوض می‌شود.

برای نصب سریع روی دامنه می‌توانم با دسترسی File Manager / پیشخوان در چند دقیقه قالب را بنشانم. لطفاً:
1. یا موقتاً دسترسی ادمین/فایل‌منیجر را خصوصی بدهید  
2. یا خودتان دو فایل نصب را طبق راهنما آپلود کنید (می‌فرستم)  
3. پرداخت مرحله ۲ را طبق پیش‌فاکتور قبل از cutover نهایی انجام دهید  
4. اگر عکس اختصاصی دارید ارسال کنید  

بعد از نصب، پیوندهای یکتا را یک‌بار ذخیره می‌کنیم و آموزش کوتاه «فقط محتوا» را می‌دهم.
