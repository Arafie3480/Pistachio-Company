# پیام آماده — تأیید ظاهر + ادامه تحویل وردپرس

جای ⟨URL⟩ را با لینک دمو پر کنید.

---

سلام آقای خراسانی،  
از تأیید ظاهر تا این مرحله ممنونم. اگر اصلاح جزئی دیگری بود بفرمایید اعمال می‌کنم.

**وضعیت:** ظاهر دمو تأیید شده و همان مبنا برای پیاده‌سازی نهایی است.  
**لینک دمو:** ⟨URL⟩

طبق قرار، مرحلهٔ بعد **پیاده‌سازی روی وردپرس** است؛ طوری که:

- ظاهر و استایل مثل همین دمو ثابت بماند  
- شما بعداً بتوانید **فقط محتوا** را از پیشخوان عوض کنید (متن، محصولات، تماس، عکس)  
- طراحی از داخل پنل به‌هم نریزد  

برای شروع پیاده‌سازی روی وردپرس لطفاً:
1. دسترسی ادمین وردپرس را خصوصی بفرستید  
2. پرداخت مرحله ۲ را طبق پیش‌فاکتور انجام دهید (قبل از انتقال دامنه)  
3. اگر عکس اختصاصی محصول/باغ دارید ارسال کنید  

بعد از آن قالب را روی محیط تست می‌سازم، محتوا را از همین دمو منتقل می‌کنم، و پس از تأیید شما روی `greendiamondfarm.com` می‌نشینیم.
