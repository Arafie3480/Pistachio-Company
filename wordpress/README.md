# WordPress theme — Green Diamond Farm

Custom locked-style theme for `greendiamondfarm.com`.  
Content editing: **Appearance → Site Content** (no page builder).

## Package

Prebuilt zip: `dist/green-diamond-farm.zip`  
One-time installer: `gdf-install.php` (upload to WP root while logged in as admin)

```bash
npm run wp:zip
# or full helper (uses WP_*/SFTP_* env when present):
npm run wp:install
```

Quick install (FA): `docs/wordpress-install-now.md`  
Full delivery notes (FA): `docs/wordpress-delivery.md`
